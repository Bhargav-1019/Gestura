# Gestura – Indian Sign Language to Text Converter

Gestura is a real-time **Indian Sign Language (ISL) to Text and Speech** system using **MediaPipe**, **Transformer (PyTorch)**, and **Gemini API** for grammar correction and translation.

---

## 🚀 Features
- Real-time hand gesture recognition via webcam
- Transformer-based sequence model
- Continuous gesture → sentence formation
- Grammar correction using Gemini API
- English → Hindi translation
- Hindi Text-to-Speech output
- Temporal smoothing for stable predictions

---

## 🧠 Tech Stack
- Python 3
- PyTorch (Transformer)
- MediaPipe
- OpenCV
- Google Gemini API
- deep-translator
- pyttsx3 / gTTS
